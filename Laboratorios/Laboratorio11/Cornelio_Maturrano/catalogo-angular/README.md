# Laboratorio 11 - Fundamentos de Angular

## Descripción

Aplicación web desarrollada con Angular 22 para visualizar
un catálogo de productos, utilizando componentes standalone,
interpolación, eventos, signals y estilos SCSS.

## Tecnologías utilizadas

- Angular CLI 22.3.0
- Node.js 26.13.1
- npm 11.20.0
- TypeScript
- HTML
- SCSS
- Visual Studio Code

## Funcionalidades

- Visualización de un catálogo de tres productos.
- Mostrar y ocultar el stock.
- Identificación visual de productos sin stock.
- Renderizado mediante @if y @for.
- Diseño adaptable mediante CSS Grid.
- Componentes independientes y reutilizables.

## Componentes implementados

- App: componente principal.
- AppHeader: cabecera de la aplicación.
- AppFooter: pie de página.
- SummaryPanel: resumen del catálogo.

## Instalación y ejecución

Instalar las dependencias:

```bash
npm install
```

Ejecutar la aplicación:

```bash
npm start
```

Abrir en el navegador:

http://localhost:4200/
